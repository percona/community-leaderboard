# Community Leaderboard Data

GitHub as a database for the [Percona Community](https://percona.community) website and the **Community Ascent** program.

This repository stores pre-generated JSON files that power the **Community Leaderboard** on the site (Basecamp, Summit Dashboard, and related Ascent pages).

## How it works

- JSON is **generated and published automatically**.

- The website widget **reads** these files over GitHub raw URLs.

- **Do not edit files here by hand** — changes will be overwritten on the next export.
